🎓 Exit Ticket & Takeaways

1. Khi nào NÊN dùng Multi-Agent?

• Tác vụ phức tạp, nhiều chặng độc lập (multi-stage workflows): Deep research, code generation + review + testing.
• Cần tách biệt vai trò (Separation of Concerns): Tránh context dilution, chuyên môn hóa prompt từng khâu.
• Cần debuggability và dynamic routing: Dễ dàng quan sát trace bước nào sai, retry có chọn lọc thay vì chạy lại từ đầu.

2. Khi nào KHÔNG NÊN dùng Multi-Agent?

• Tác vụ đơn giản 1 bước (Single-step tasks): Tóm tắt văn bản ngắn, phân loại sentiment, Q&A cơ bản.
• Yêu cầu độ trễ cực thấp (Ultra-low latency): Multi-agent tốn thời gian handoff và supervisor routing tuần tự.
• Ngân sách token thấp: Chi phí token cao gấp 3-4 lần so với single prompt.
